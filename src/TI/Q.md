## React Core

### Basic

+ * React component definition (functional component)
+ * JSX (embedding expressions, attributes, children)
+ * React component state (initial state, useState, lazy initialization)
+ * React component lifecycle (render, pre-commit, commit, error boundaries)
+ * Hooks (types, use cases, rules)
+ * Components composition (props.children, inheritance vs composition, lifting state up, decomposition task)

### Intermediate

* React DOM (useRef, createRef, ref forwarding, callback refs, SyntheticEvent)
* Forms (controlled/uncontrolled components)
* Context (useContext, Context.Provider, Context.Consumer)
* Performance (memo, useMemo, useCallback, keys, profiler)

### Advanced

* React code reuse patterns (custom hooks, HOC, render props)
* Virtual DOM (concept, reconciliation, keys, Fiber architecture)
* Security (XSS on React props, dangerouslySetInnerHTML)

## React Ecosystem

### Basic

* Typechecking (TypeScript)
* Redux (principles: actions, reducers, store, unidirectional flow, data normalization, Redux vs Context)

### Intermediate

* React Redux (presentational vs container, Provider, connect, useSelector, useDispatch)
* Redux Async Flow (middleware, Thunk)
* Routing (react-router, jsx/object configuration, history)

### Advanced

* Automated testing (React Testing Library, Enzyme, e2e: Playwright, Cypress, Puppeteer)
* Building (transpilers, bundlers, dev vs production build, code splitting, build optimization)
* Server rendering (CSR vs SSR, cases of usage)
* Static site rendering (Next.js, Gatsby)
