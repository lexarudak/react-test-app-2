# 🧩 Hooks (types, use cases, rules)

**Хуки** — это обычные **JS-функции**, имя которых начинается с `use`, и которые **внутри себя вызывают другие хуки React**.
Они позволяют **инкапсулировать и переиспользовать логику** между компонентами без использования классов или HOC.

---

## 🔹 Типы хуков

1. **Хуки состояния**

   * `useState`, `useReducer`
     — управляют состоянием внутри компонента.
     Позволяют хранить данные между рендерами.

2. **Хуки побочных эффектов / жизненного цикла**

   * `useEffect`, `useLayoutEffect`
     — синхронизируют компонент с внешним миром (таймеры, запросы, DOM-эффекты и т.д.).

3. **Хуки контекста**

   * `useContext` (или `useSelector` в Redux)
     — дают доступ к состоянию, общему между компонентами.

4. **Хуки ссылок и измерений**

   * `useRef`
     — дают доступ к элементам DOM или сохраняют мутабельные значения.

5. **Хуки оптимизации**

   * `useMemo`, `useCallback`, `useTransition`
     — оптимизируют производительность, кешируя значения и функции.

6. **Пользовательские хуки (custom hooks)**
   — позволяют объединять и переиспользовать несколько хуков как единую логическую единицу.
   — пример:

   ```tsx
   function useFetch<T>(url: string) {
     const [data, setData] = useState<T | null>(null);
     useEffect(() => {
       fetch(url).then(res => res.json()).then(setData);
     }, [url]);
     return data;
   }
   ```

---

## ⚙️ Правила хуков

1. **Вызывай хуки только на верхнем уровне.**
   Нельзя вызывать их внутри `if`, `for`, `switch`, или вложенных функций.
   Это нужно, чтобы **порядок вызовов хуков оставался стабильным** от рендера к рендеру.

2. **Вызывай хуки только из:**

   * функциональных компонентов,
   * или других хуков.

   Нельзя вызывать их в обычных функциях, классах или условиях.

3. **Почему так:**
   Внутри React каждый компонент хранит хуки как **связанный список** в поле `fiber.memoizedState`.
   При ререндере React просто **проходит по этому списку** и сопоставляет вызовы по порядку.
   Если порядок нарушится (например, вызов внутри `if`), — React не поймёт, какой хук к чему относится.

---

## 💡 Use cases (где применяются)

* **Состояние и эффекты компонента** (`useState`, `useEffect`)
* **Оптимизация** (`useMemo`, `useCallback`)
* **Общий контекст** (`useContext`)
* **Асинхронные операции и переходы** (`useTransition`, `useDeferredValue`)
* **Переиспользуемая бизнес-логика** (кастомные хуки)

---

## 🧠 Ключевая мысль

> Хуки — это **способ композиции логики**, а не UI.
> Компоненты — это композиция JSX,
> хуки — композиция поведения.
